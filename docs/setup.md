# Setup

- Pré-requisitos: Node `^22.22.3 || ^24.15.0 || >=26`, npm.
- `npm install` → `npm start` (porta 4200).
- Testes: `npm test`. Build: `npm run build` (saída em `dist/minas-explorer/browser`).
- Sem variáveis de ambiente, chaves de API ou backend.
- Observação: `lucide-angular` 1.0.0 não declara suporte ao Angular 22; usamos o pacote oficial `@lucide/angular`.
